# 설치와 실행

> **주의.** 아래는 **2026-10 에 실제로 돌렸던 조합의 기록**이지 "이대로 하면
> 반드시 된다"는 보장이 아니다. 당시 환경은 임시 폴더에 깔았다가 지워졌고,
> 재설치를 검증하지 못했다.
>
> 1·2·4 번(녹화·KISS-ICP·ReBound)은 평범한 pip 설치라 위험이 작다.
> **3 번(검출기)만 까다롭다** — torch·mmcv·mmdet3d·numpy 버전이 서로 맞아야
> 하고, 안 맞으면 조용히 실패한다.

## 2. KISS-ICP (2 단계 오도메트리)

```bash
pip install kiss-icp
```

1.3 부터 `odom.poses` 가 없어지고 `odom.last_pose` 만 남아서, 프레임마다 모아 둔다.

## 3. 검출기 (6 단계) — 가장 까다롭다

> 아래는 [`../자동라벨링_실험.md`](../자동라벨링_실험.md) 에 적어 둔 **실제로 돌렸던 구성**이다.
> CUDA 확장을 직접 컴파일하지 않고 **사전 빌드 휠만으로** 맞췄다.

| | 버전 | 왜 이 버전인가 |
|---|---|---|
| torch | **2.1.0+cpu** | mmcv 사전 빌드 휠이 이 버전까지만 있다 |
| mmcv | **2.1.0** | |
| mmdet / mmdet3d | **3.2.0 / 1.4.0** | |
| **numpy** | **< 2** | **torch 2.1 이 numpy 1.x 로 빌드됐다. 2.x 면 깨진다** |

```bash
pip install "numpy<2"
pip install torch==2.1.0 torchvision --index-url https://download.pytorch.org/whl/cpu
pip install -U openmim
mim install mmengine
pip install mmcv==2.1.0 -f https://download.openmmlab.com/mmcv/dist/cpu/torch2.1/index.html
mim install "mmdet==3.2.0" "mmdet3d==1.4.0"
```

**가중치** — PointPillars nuScenes, 24 MB

```
hv_pointpillars_fpn_sbn-all_4x8_2x_nus-3d_20210826_104936-fca299c1.pth
```

mmdetection3d 모델 주에서 받는다. 받은 뒤 `pp_nus.pth` 로 두고 썼다.
설정 파일은 패키지 안에 들어 있다:
`<site-packages>/mmdet3d/.mim/configs/pointpillars/pointpillars_hv_fpn_sbn-all_8xb4-2x_nus-3d.py`

### 겪었던 문제

| 증상 | 원인 | 해결 |
|---|---|---|
| `numba` import 실패 | 시스템의 오래된 `coverage` 와 충돌 | `pip install --upgrade coverage` |
| GPU 를 못 씀 | RTX 5060 은 Blackwell(compute 12.0) 이라 torch 2.7+/cu128 필요. 그런데 mmcv 사전 빌드 휠이 그 버전에 없다 | **CPU 로 돌렸다.** 키프레임당 약 3 초 |

**CenterPoint 대신 PointPillars 를 쓴 이유**: CenterPoint 는 희소 합성곱이라 CPU 에서 막힐 수 있다.
PointPillars 는 pillar scatter 후 2D 합성곱만 쓴다.

### 지금 이 노트북에는 없다

이 환경을 임시 폴더(`/tmp/.../scratchpad/det`)에 깔았다가 **지워졌다.**
가중치 파일도 남아 있지 않다. 6 단계를 다시 돌리려면 위 순서대로 새로 깔아야 하고,
**그 과정을 아직 재검증하지 못했다.**

다시 깔 때는 `/tmp` 가 아니라 `~` 아래 영구 위치에 깔고, 받은 가중치를 따로 보관할 것.

## 4. ReBound (9~10 단계 라벨링 툴)

```bash
git clone https://github.com/ajedgley/ReBound ~/Documents/ReBound
cd ~/Documents/ReBound
git apply <이 폴더>/rebound.patch
```

`rebound.patch` 가 고치는 것:

| 증상 | 원인 | 수정 |
|---|---|---|
| 프레임 3 에서 창이 꺼짐 | `np.asarray(Image.open(...))` 가 읽기전용인데 cv2 로 그린다 | `np.array` 로 (4 곳) |
| 박스가 거의 안 보임 | 기본 confidence 임계값이 50, 우리 점수는 10~55 | 기본 10 |
| 드래그가 제멋대로 | `unproject` 가 깊이를 모른다 | 화면 픽셀 변화량 × 카메라 기준 |

의존 패키지는 `run_rebound.sh` 가 `~/.local/rebound_libs` 에 알아서 깐다
(open3d, nuscenes-devkit, pyquaternion, matplotlib).

## 실행 순서

세션 하나를 처음부터 끝까지:

```bash
cd <레포>
bash 데이터_라벨링/code/run_session.sh 041 2026-10-06
```

2(오도메트리) → 5(키프레임) → 6(검출) → 7(다듬기) → 7.5(꼬깔콘) → 8(ReBound)
→ 확인 영상 순서로 돈다. **이미 끝난 단계는 건너뛴다.**

| 환경변수 | |
|---|---|
| `SKIP_REBOUND=1` | 8 단계를 건너뛴다 |

### 하나씩 돌릴 때

```bash
C=데이터_라벨링/code
R=포인트보정/results/2026-10-06_session_041
S=~/ros2_ws/cam_lidar_recording/sessions/session_041

python3 $C/run_kiss_icp.py $S/lidar.pcap --voxel 0.2 --max-range 25 -o $R/deskew_on
python3 $C/select_keyframes.py $S --poses $R/deskew_on --min-dist 1.0 --max-gap 3.0 -o $R/keyframes.json
python3 $C/auto_label.py $S --poses $R/deskew_on --keyframes $R/keyframes.json \
        --config <mmdet3d 설정> --checkpoint ckpt/pp_nus.pth --score 0.1 -o $R/autolabel
python3 $C/refine_boxes.py $S --poses $R/deskew_on \
        --detections $R/autolabel/detections.json --max-range 30 -o $R/autolabel/refined.json
python3 $C/detect_cones.py $S --poses $R/deskew_on --keyframes $R/keyframes.json \
        --vehicles $R/autolabel/refined.json --taper 1.05 -o $R/autolabel/cones.json
python3 $C/to_rebound.py $S --poses $R/deskew_on --keyframes $R/keyframes.json \
        --detections $R/autolabel/refined.json --extra $R/autolabel/cones.json \
        --n-sweep 30 -o ~/ros2_ws/cam_lidar_recording/rebound/session_041
python3 $C/render_lidar_3d.py $S --poses $R/deskew_on \
        --detections $R/autolabel/refined.json --extra $R/autolabel/cones.json \
        --eye=-22,0,16 --target=4,0,-0.5 --n-sweep 30 --color height \
        --drop-ground 0.25 --max-height 2.2 -o $S/lidar3d.mp4
```

**`--max-range` 는 장소마다 다르다.** [`README.md`](README.md) 의 표 참고.
