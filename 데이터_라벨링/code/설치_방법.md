# 설치와 실행

> **주의.** 아래 버전은 **2026-10 에 실제로 돌렸던 조합을 기록한 것**이지,
> "이대로 하면 반드시 된다"는 보장이 아니다. 당시 환경은 임시 폴더에 깔았다가
> 지워졌고, 다시 검증하지 못했다. 특히 mmdetection3d 는 torch·mmcv 버전이
> 서로 맞아야 하고 안 맞으면 조용히 실패한다.

## 4. ReBound (9~10 단계 라벨링 툴)

```bash
git clone https://github.com/ajedgley/ReBound ~/Documents/ReBound
cd ~/Documents/ReBound
git apply <이 폴더>/rebound.patch
```

`rebound.patch` 가 고치는 것:

| 증상 | 원인 | 수정 |
|---|---|---|
| 프레임 3 에서 창이 꺼짐 | `np.asarray(Image.open(...))` 가 읽기전용인데 cv2 로 그린다 | `np.array` 로 (4 곳) |
| 박스가 거의 안 보임 | 기본 confidence 임계값이 50, 우리 점수는 10~55 | 기본 10 |
| 드래그가 제멋대로 | `unproject` 가 깊이를 모른다 | 화면 픽셀 변화량 × 카메라 기준 |

의존 패키지는 `run_rebound.sh` 가 `~/.local/rebound_libs` 에 알아서 깐다
(open3d, nuscenes-devkit, pyquaternion, matplotlib).

## 실행 순서

세션 하나를 처음부터 끝까지:

```bash
cd <레포>
bash 데이터_라벨링/code/run_session.sh 041 2026-10-06
```

2(오도메트리) → 5(키프레임) → 6(검출) → 7(다듬기) → 7.5(꼬깔콘) → 8(ReBound)
→ 확인 영상 순서로 돈다. **이미 끝난 단계는 건너뛴다.**

| 환경변수 | |
|---|---|
| `SKIP_REBOUND=1` | 8 단계를 건너뛴다 |

### 하나씩 돌릴 때

```bash
C=데이터_라벨링/code
R=포인트보정/results/2026-10-06_session_041
S=~/ros2_ws/cam_lidar_recording/sessions/session_041

python3 $C/run_kiss_icp.py $S/lidar.pcap --voxel 0.2 --max-range 25 -o $R/deskew_on
python3 $C/select_keyframes.py $S --poses $R/deskew_on --min-dist 1.0 --max-gap 3.0 -o $R/keyframes.json
python3 $C/auto_label.py $S --poses $R/deskew_on --keyframes $R/keyframes.json \
        --config <mmdet3d 설정> --checkpoint ckpt/pp_nus.pth --score 0.1 -o $R/autolabel
python3 $C/refine_boxes.py $S --poses $R/deskew_on \
        --detections $R/autolabel/detections.json --max-range 30 -o $R/autolabel/refined.json
python3 $C/detect_cones.py $S --poses $R/deskew_on --keyframes $R/keyframes.json \
        --vehicles $R/autolabel/refined.json --taper 1.05 -o $R/autolabel/cones.json
python3 $C/to_rebound.py $S --poses $R/deskew_on --keyframes $R/keyframes.json \
        --detections $R/autolabel/refined.json --extra $R/autolabel/cones.json \
        --n-sweep 30 -o ~/ros2_ws/cam_lidar_recording/rebound/session_041
python3 $C/render_lidar_3d.py $S --poses $R/deskew_on \
        --detections $R/autolabel/refined.json --extra $R/autolabel/cones.json \
        --eye=-22,0,16 --target=4,0,-0.5 --n-sweep 30 --color height \
        --drop-ground 0.25 --max-height 2.2 -o $S/lidar3d.mp4
```

**`--max-range` 는 장소마다 다르다.** [`README.md`](README.md) 의 표 참고.
